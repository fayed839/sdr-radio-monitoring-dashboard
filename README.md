# SDR-Based Radio Monitoring Dashboard

## Overview
A radio-frequency monitoring and visualization portfolio project using **Software Defined Radio (SDR)** concepts to observe authorized/open radio spectrum activity and present measurements in a dashboard-style workflow.

The project highlights my interest in the intersection of **RF engineering, wireless technology, signal analysis, Linux, data visualization, and cybersecurity**.

## Skills Demonstrated
- Software Defined Radio (SDR)
- RF spectrum observation
- Signal visualization
- Data collection and analysis
- Dashboard design
- Linux / technical troubleshooting
- Wireless-security awareness

## Project Goals
- Capture spectrum information from SDR hardware.
- Visualize signal strength and frequency activity.
- Document the SDR signal chain and antenna configuration.
- Create repeatable monitoring workflows.
- Analyze only transmissions I am legally authorized to receive/observe.
